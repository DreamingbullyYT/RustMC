Horizon Rust Android upstream port — development snapshot (2026-11-11)

Base: upstream/main commit 1405044d0996d37f850f5ab0dec02bab43d4945f
Working branch: upstream-port-android (git history not included)

Latest check:
  cargo check -p horizon-android --target aarch64-linux-android
Result: 0 errors (was 209). Type-check only: not linked, no APK built, nothing run on a device.
Checked with a locally built std (-Zbuild-std) and a stand-in C compiler for build scripts, so a
real NDK build may still show link-time or C-dependency problems. The shared crates touched
(horizon-protocol, horizon-client-input, horizon-client-render) also pass a host cargo check.

What changed
- touch_compat.rs: Android-owned touch settings. Wraps upstream's layout Settings (Deref) and adds
  control style, presets, profiles, gyro, vibration, virtual mouse. No obsolete fields in core.
- runtime_compat.rs: Android launcher knobs (cache dir, clipboard, graphics prefs, worker limit,
  texture budget, graphics-start crash marker, launcher-return flag).
- port_compat.rs: stand-in for the missing on-device port API.
- Shared engine hooks (small): Renderer::suspend_surface (gfx.rs), Android clipboard hooks
  (horizon-client-input clipboard.rs), install_system_srv_lookup (horizon-protocol resolver).
- Mod browser: data-pack install into worlds removed; native-mod and i18n helpers made local.

Known gaps (compiles, but not functional yet)
- Visual touch-layout editor removed (it came from a touch UI module upstream lacks). "Open
  editor" shows a notice. Presets, import/export and sliders remain.
- Java mod / modpack / data-pack porting returns "not available in this build".
- Quit-from-game does not yet return to the launcher: nothing sets the launcher-return flag, so
  the engine's event_loop.exit() ends the app.
- packaging/android/bedrock-controls.json is an empty placeholder (its file hashes were not in
  the snapshot): Bedrock control textures are not downloaded.
- Skin head uses the public Mojang profile lookup only; no built-in shader packs; Discord
  presence and the game's appearance handoff are not wired.
- Mixed-in unit tests for the removed data-pack install are disabled with cfg(any()).

Next: set up the NDK, build the APK, install with ADB, check logcat, reach a world, test touch,
sound, pause/resume and resource download.

This is a development snapshot, not a release. It contains no APK or signing credentials.
